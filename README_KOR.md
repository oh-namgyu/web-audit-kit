# web-audit-kit (한국어 소개)

> 대상 URL 을 **비침습적으로 점검**해 보안·UX/디자인·아키텍처·기능 QA 네 관점으로 리포트를 만드는 로컬 사이트 감사 도구.

[English README](README.md)

## 어떤 문제를 푸나

사이트를 빠르게 점검하고 싶을 때, 무거운 스캐너를 붙이거나 수동으로 헤더·DOM 을 들여다보는 건 번거롭습니다. web-audit-kit 은 로컬 우선 감사 도우미로, 대상 URL 을 열어 **수동적(passive) 브라우저·헤더 증거**를 모으고 Markdown/HTML/JSON 리포트를 만듭니다.

## 핵심 기능

- 한 URL → **4관점 리포트**: 보안 / UX·디자인 / 아키텍처 / 기능 QA
- 헤더 + Playwright DOM·네트워크 증거를 수동적으로 수집 (공격 아님)
- Markdown/HTML/JSON 출력, 선택적 이메일 발송

## 안전 수칙

본인이 소유했거나 명시적 허가를 받은 시스템만 감사하세요. 기본값은 `127.0.0.1` 바인드 + 메일 비활성. 인증·대상 화이트리스트·레이트리밋 없이 외부에 노출하면 내부망 스캐닝/SSRF 도구로 악용될 수 있습니다.

## 기술 스택

Node.js 20+ · Playwright · 로컬 우선

## 이 프로젝트의 핵심 포인트

"비침습(passive)"이 설계의 중심입니다 — 공격이 아니라 관찰로만 증거를 모으고, 외부 노출 시의 SSRF 악용 위험까지 README 에 명시한 **방어적 보안 도구**라는 점이 차별점입니다.
